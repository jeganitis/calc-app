## Function: main()
Entry point. Creates a `tk.Tk()` root, passes it to `Calculator`, and starts the tkinter event loop with `root.mainloop()`. Returns nothing.

## Known Limitations
- `eval()` is used for expression evaluation. The `allowed_chars` guard prevents code injection but does not validate expression structure (e.g. "5++3" will raise an exception).
- Floating point results may show precision artifacts for complex expressions (e.g. 0.1 + 0.2 = 0.30000000000000004).
- No keyboard input support — mouse/touch only.
