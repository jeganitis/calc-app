## How It Works

The calculator uses tkinter for the GUI and operates on a simple expression string model. When the user clicks buttons (digits or operators), they're appended to the expression. When "=" is pressed, the `_evaluate()` method safely evaluates the expression using Python's `eval()` guarded by an `allowed_chars` check to prevent code injection. Results are displayed immediately, with whole numbers formatted cleanly (25 instead of 25.0).
