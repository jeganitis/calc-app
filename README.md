# Calculator App

A simple desktop calculator built with Python and tkinter.

## Features (Phase 2)
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Requirements
- Python 3.8 or higher
- No external packages needed (tkinter is built into Python)

## Run

```bash
python calculator.py
```

## How It Works

The calculator uses a tkinter event loop to handle button presses. When the user clicks "=", the `_evaluate()` method parses the expression and uses `eval()` with a character whitelist guard to safely compute the result. Results are displayed in the text entry field, and invalid inputs show error messages.
