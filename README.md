# Calculator App

A simple desktop calculator built with Python and tkinter.

## Features (Phase 1)
- Addition (+)
- Subtraction (-)

## Requirements
- Python 3.8 or higher
- No external packages needed (tkinter is built into Python)

## Run

    python calculator.py
